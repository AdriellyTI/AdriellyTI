# Portfólio pessoal — AdriellyTI

Site pessoal responsivo, com estética inspirada na imagem/logo enviada: rosa vibrante, lavanda, branco, pixel art e detalhes arredondados.

## Estrutura

- `index.html` — conteúdo e links
- `styles.css` — layout, cores, responsividade e animações
- `script.js` — máquina de escrever, animações de entrada, cursor, gatinha interativa e tema claro/escuro
- `assets/logo.png` — logo enviada
- `assets/cat.png` — recorte da gatinha pixel art

## Como usar

Não precisa de framework. Abra `index.html` no navegador.

Para desenvolver localmente, pode usar a extensão Live Server do VS Code.

## Personalização rápida

1. Substitua o bloco `SEU ROSTO / adicione sua foto` em `index.html` pela sua foto.
2. Edite textos, hobbies e projetos.
3. Adicione/remova redes sociais na seção "Como me encontrar".
4. Para publicar, o projeto pode ser colocado no GitHub Pages, Netlify ou Vercel.

## Tecnologias

HTML5, CSS3 e JavaScript puro.
